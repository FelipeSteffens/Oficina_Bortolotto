# Oficina Bortolotto

MVP de gestão de clientes, veículos e ordens de serviço.

Consulte [DOCUMENTACAO.md](DOCUMENTACAO.md) para requisitos, DER e instruções completas de instalação. O SQL inicial está em [banco.sql](banco.sql).

## Estrutura

- `backend/src`: API Express, autenticação, criptografia e SQLite.
- `frontend/src`: interface React para login, clientes, veículos e ordens de serviço.
- `banco.sql`: esquema e dados iniciais fictícios.
